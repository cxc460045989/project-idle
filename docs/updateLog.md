## 🌍 轮回世界

### 新增难度选择系统

**日期**: 2026-03-10

**功能说明**:
- 进入轮回世界前增加难度选择对话框
- 提供两种难度：普通、困难
- 不同难度影响怪物属性系数

**难度设置**:
| 难度 | 图标 | 怪物属性系数 | 说明 |
|------|------|-------------|------|
| 普通 | ⚔️ | 1.0 倍 | 标准难度，适合新手 |
| 困难 | 💀 | 2.0 倍 | 所有属性翻倍，适合挑战 |

**实现细节**:
1. 点击「进入轮回世界」按钮后弹出难度选择对话框
2. 选择难度后确认进入战斗
3. 战斗界面显示当前难度标签
4. 难度信息传递给怪物创建函数

**代码位置**:
- `src/components/MainHub.vue` - 添加难度选择对话框和相关函数
- `src/components/BattleScreen.vue` - 添加难度显示和传递
- `src/js/EntityManager.js` - 怪物创建时应用难度系数
- `src/styles/main.scss` - 添加难度选择对话框和标签样式

### 怪物血量调整

**日期**: 2026-03-10

**调整内容**:
根据怪物类型调整基础血量倍率：

| 怪物类型 | ID 范围 | 血量倍率 | 说明 |
|---------|--------|---------|------|
| 普通怪物 | < 3000 | 1.2 倍 | +20% |
| 精英怪物 | 3000-8999 | 1.5 倍 | +50% |
| Boss 怪物 | ≥ 9000 | 2.5 倍 | +150% |

**最终血量计算**:
```
怪物血量 = 基础血量 × 类型倍率 × 难度系数
```

**示例**:
- 普通怪物（普通难度）：100 × 1.2 × 1.0 = 120 HP
- 普通怪物（困难难度）：100 × 1.2 × 2.0 = 240 HP
- Boss 怪物（困难难度）：100 × 2.5 × 2.0 = 500 HP

## 技术问题解决记录

### 2026-03-10: Windows 环境下文件创建问题的解决方案

**问题**: `write_file` 工具报错 "Error checking existing file: [object Object]"，无法直接创建文件

**尝试的失败方案**:
1. `echo "内容" > "完整路径"` - Windows cmd 对长路径引号处理有问题
2. PowerShell `Set-Content` - 命令中包含特殊字符被安全策略阻止

**成功方案**:
```bash
# 1. 先创建空文件
cd 目标目录 && type nul > 文件名

# 2. 再写入内容
cd 目标目录 && echo 第一行 > 文件名 && echo 第二行 >> 文件名
```

**经验总结**: Windows 环境下，使用 `type nul >` 创建空文件是最可靠的方式，然后通过 `echo` 逐行追加内容。
