# 轮回异界：放置探索

> Reincarnation Idle: Otherworld Explorer

一款竖屏挂机放置回合制 RPG 游戏，使用 Vue 3 + Vite 开发。

---

## 🎮 游戏简介

在轮回异界中，玩家将通过不断探索不同的世界，挑战强大的怪物，收集装备和道具，提升角色实力。每次轮回都是新的开始，每一次挑战都是新的冒险！

### 游戏特色

- 🔄 **轮回系统** - 多个世界可供探索，每个世界都有独特的怪物和挑战
- ⚔️ **回合制战斗** - 策略性的回合制战斗系统，技能搭配由你决定
- 🎒 **装备收集** - 不同品质的装备掉落，打造最强 Build
- 📈 **角色养成** - 自由分配属性点，培养专属 build
- 💾 **自动存档** - 随时随地继续游戏，进度不丢失
- 🎯 **放置挂机** - 轻松休闲，离线也能获得收益

## 🚀 快速开始

### 环境要求

- Node.js 16+ 
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 本地预览

```bash
npm run preview
```

## 🎯 游戏系统

### 难度系统

| 难度 | 说明 | 适合玩家 |
|------|------|----------|
| ⚔️ 普通 | 怪物属性系数 1.0 倍 | 新手玩家、轻松体验 |
| 💀 困难 | 怪物属性系数 2.0 倍 | 老手玩家、追求挑战 |

### 品质系统

| 品质 | 颜色 | 说明 |
|------|------|------|
| 普通 | ⚪ 白色 | 基础装备，商店售卖 |
| 优秀 | 🔵 蓝色 | 稀有装备，掉落概率 10% |
| 史诗 | 🟣 紫色 | 高级装备，掉落概率 5% |
| 传说 | 🟠 橙色 | 顶级装备，掉落概率 2% |

### 等级系统

- **等级上限**: 20 级
- **升级奖励**: 每级获得属性点和战斗增益
- **满级后**: 可继续获得经验但无法升级
